# matlab-music-player
A MATLAB App Designer music player with audio processing and signal visualisation.

## How to Run

1. Download the repository using Code → Download ZIP.
2. Extract the ZIP and keep all files in the same folder.
3. Open MATLAB and set Current Folder to the extracted folder.
4. Run:

```matlab
app = MP3English;
```

5. Click Import, select a local audio file, select the track
   in the playlist, and press Play.

The interface is in English.
Signal Processing Toolbox is required for vocal reduction.
Use stereo audio when testing the delay and vocal-reduction functions.
